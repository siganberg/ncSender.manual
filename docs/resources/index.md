# Resources

Guides and cheat-sheets for things that live **outside** ncSender itself but
still trip people up when getting a CNC running — controller firmware quirks,
hardware wiring, and third-party integrations.

These pages aren't part of ncSender's own documentation; they're field notes.
Details can change with new firmware releases or hardware revisions, so treat
every number as a starting point and cross-reference your controller /
hardware manual before flashing settings blindly.

## In this section

- **[VFD Setup (RS485/ModBus)](vfd-setup.md)** — grblHAL settings and matching
  parameters for the most common CNC-router VFDs: Huanyang v1, Huanyang P2A,
  H100 (Zhong Hua Jiang), and PwnCNC (MODVFD).
