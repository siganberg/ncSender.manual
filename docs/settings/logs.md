# Logs

ncSender keeps a log file for each day. Support may ask for one when you report a problem. Open **Settings → Logs**.

## Open Today's Log

1. Open **Settings → Logs**.
2. Pick a log file from the list. Today's log is the newest.
3. Click **Refresh** to see new lines.

<!-- CAPTURE NEEDED: assets/images/settings/logs-tab.webp (Logs tab) -->

The bottom shows the folder where logs are stored and how many log files there are.

## Send a Log for Support

1. Pick the log from the day the problem happened.
2. Click **Download**. On a kiosk, click **Save** and pick an external drive.
3. Attach the file to your support request or Discord post.

## Clear Old Logs

1. Pick the log file.
2. Click **Delete** and confirm.

Today's log is still in use, so ncSender clears its contents instead of deleting it. Click **Clear** to confirm.
