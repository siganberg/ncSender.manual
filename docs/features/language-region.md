# Language & Region

!!! info "Pro Feature"
    Language & Region is available in **ncSender Pro** only.

Choose the language ncSender uses for labels and instructions, and the letter layout of the on-screen keyboard.

## Change the Language

1. Open **Settings → General**.
2. Scroll to **Language & Region**.
3. Pick a **Language**: English, Deutsch, Français or Español.

<!-- CAPTURE NEEDED: assets/images/features/language-region.webp (Language & Region settings) -->

The screen changes right away. Every screen connected to this ncSender changes with it.

<!-- CAPTURE NEEDED: assets/images/features/language-german-ui.webp (ncSender in German) -->

## What Is Translated

- Labels, descriptions and instructions
- Alarm names and how to fix them
- The **Space**, **Enter** and **Done** keys on the on-screen keyboard

Anything not yet translated shows in English. Messages that come straight from your controller stay as the controller sends them.

## Keyboard Layout

Changing **Language** also sets the on-screen keyboard to that language's layout:

| Language | Keyboard layout |
|---|---|
| English | English (US) · QWERTY |
| Deutsch | Deutsch · QWERTZ |
| Français | Français · AZERTY |
| Español | Español · QWERTY |

<!-- CAPTURE NEEDED: assets/images/features/language-keyboard-follows.webp (Keyboard layout follows the language) -->

The number pad stays the same for every layout. See [Virtual Keyboard](virtual-keyboard.md).

## Use a Different Layout

You can keep one language and use another keyboard layout, for example English with a Swiss keyboard.

1. Set the **Language** first.
2. Then pick a layout in **On-screen Keyboard Layout**.

Pick the language first, because changing the language resets the layout.
